# Share Link Saver

**分享链接保存工具 · 纯 Python · 跨平台 · 零外部依赖**

## 用法

```bash
python3 share-link-saver.py "https://chatgpt.com/share/xxxx-xxxx"
python3 share-link-saver.py "https://chatgpt.com/share/xxxx-xxxx" --out ./存档
python3 share-link-saver.py "https://chatgpt.com/share/xxxx-xxxx" --format txt
```

仅需 Python 3.8+。
