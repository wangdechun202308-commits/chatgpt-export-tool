# ChatGPT 分享链接导出工具

**纯 Python · 跨平台 · 零外部依赖**

## 用法

```bash
python3 chatgpt-export.py "https://chatgpt.com/share/xxxx-xxxx"
python3 chatgpt-export.py "https://chatgpt.com/share/xxxx-xxxx" --out ./导出
python3 chatgpt-export.py "https://chatgpt.com/share/xxxx-xxxx" --format txt
```

仅需 Python 3.8+。
